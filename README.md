# صبا بغداد — التطبيق v3 (إعادة بناء كاملة)

هذه نسخة مكتوبة من الصفر بكود نظيف. الشكل وترتيب الأقسام والتابات واللغات الثلاث نفس التطبيق القديم، ويشتغل على أودو مباشرة.

- **ما بقت صيغة ذكر/أنثى.** كل العبارات صارت بصيغة محايدة، مثل «شنو تحتاجون اليوم؟» و«اكتبوا هنا … وإحنا نساعدكم». شاشة «شلون نحچيك؟» انحذفت.
- **كل صفحة إلها رابط حقيقي**: `/products` و`/product/165` و`/cart` وغيرها. زر الرجوع بالموبايل يشتغل صح.
- **حجم التطبيق صار أصغر هواي.** الصفحة الوحدة كانت 1.6 ميغا، هسه التطبيق كامل (كود وشعارات) حوالي 280 كيلوبايت.

---

## ترتيب التطبيق

**الشريط السفلي** (من اليمين): الرئيسية · الأقسام · المنتجات · سلتي · الحساب

| التاب | المحتوى (بنفس الترتيب القديم) |
|---|---|
| الرئيسية | البحث ← البنرات ← «شنو تحتاجون اليوم؟» ← منتجات ترند ← منتجات مميزة ← الماركات (٩ + عرض الكل) ← ليش تشترون من صبا ← أزرار الواتساب والتوقيع |
| الأقسام | البحث ← شجرة الأقسام |
| الحساب | دخول / حساب جديد / حسابي وحذف الحساب ← طلباتي ← تواصلوا ويانا ← تابعونا ← التوقيع |

الشاشات الداخلية: المنتجات، المنتج، السلة، طلباتي، من نحن، الخدمات والآراء. فوق كل وحدة شريط بيه «رجوع» يرجعكم للشاشة اللي قبلها بنفس الفلتر، و«✕» يرجعكم للتاب اللي بديتوا منه.

## ملفات المشروع

```
index.html              الصفحة الوحيدة (التطبيق يشتغل منها)
404.html                أي رابط غلط يرجع للرئيسية
vercel.json             مسارات الصفحات + التحويل من الروابط القديمة (contact.html وغيرها)
css/app.css             كل الألوان والتصميم (الألوان بأول الملف)
img/brand/              الشعار والأيقونات
img/content/            صور البنرات والأقسام (بعد تشغيل download-assets.mjs)
js/
  config.js             رقم الواتساب، الروابط، مكان الصور، الدردشة
  i18n.js               كل النصوص بالعربي والإنجليزي والكردي
  data/content.js       البنرات، الحالات، الأقسام، الماركات، المنتجات المختارة
  data/pages.js         نصوص «من نحن» و«الخدمات والآراء»
  router.js             التنقل بين الشاشات وزر الرجوع
  store.js              السلة، الحساب، الطلبات (محفوظة بالجهاز)
  api.js                الاتصال بـ /api
  components/           الهيدر، البحث، الأقسام، الشريط السفلي
  views/                كل شاشة بملف
api/                    سيرفر صغير على Vercel يكلّم أودو (المفتاح ما يطلع للموبايل)
  _lib/                 أدوات مشتركة
```

**تعديلات سريعة:**
- تغيير بنر أو ماركة أو منتج بالرئيسية: من `js/data/content.js`.
- تغيير نص: من `js/i18n.js`.
- تغيير لون: من أول ملف `css/app.css`.

## النشر على Vercel

1. ارفعوا مجلد `saba-app` على مشروعكم بـ Vercel، إما بـ GitHub أو بأمر `vercel --prod` من داخل المجلد. ما يحتاج Build.
2. من **Settings ← Environment Variables** ضيفوا:

| الاسم | القيمة | ملاحظة |
|---|---|---|
| `ODOO_URL` | `https://saba-baghdad.odoo.com` | مطلوب |
| `ODOO_DB` | اسم قاعدة البيانات | مطلوب |
| `ODOO_LOGIN` | إيميل مستخدم أودو صاحب المفتاح | مطلوب |
| `ODOO_API_KEY` | مفتاح الـ API | مطلوب، لا تكتبوه بأي ملف |
| `SESSION_SECRET` | نص عشوائي طويل (٣٢ حرف أو أكثر) | **مهم**: بيه تتوقّع جلسات الدخول وأرقام الطلبات |
| `HEALTH_KEY` | كلمة سر للفحص (٨ أحرف أو أكثر) | اختياري |
| `DELIVERY_FEE_BAGHDAD` / `DELIVERY_FEE_PROVINCES` | مثلاً `4000` / `5000` | اختياري. بدونهم تبقى الأجور 4,000 لبغداد و5,000 للمحافظات |
| `ORDER_AUTO_CONFIRM` | `false` | اختياري. بدونه الطلب يتأكد تلقائياً مثل قبل. إذا حطيتوه `false` يبقى الطلب «عرض سعر» لحد ما الفريق يأكده |

3. بعد إضافة المتغيرات سوّوا **Redeploy**.
4. للفحص افتحوا `https://<الموقع>/api/health?key=<HEALTH_KEY>`. لازم تطلع `"ok": true` وعدد المنتجات المنشورة.

إذا Appilix يفتح نفس رابط Vercel، ما يحتاج أي تغيير بالتطبيق المنشور على المتاجر.

## الصور (مهم قبل إلغاء Mocha)

صور البنرات والأقسام والماركات بعدها على سيرفر Mocha. من داخل المجلد شغّلوا:

```bash
node download-assets.mjs
```

الأمر ينزّل الـ 58 صورة إلى `img/content/` ويحوّل `js/config.js` عليها تلقائياً. بعدها انشروا مرة ثانية، وتگدرون تلغون اشتراك Mocha.

## شنو تصلّح بالمقارنة مع النسخة القديمة

**الأمان والخصوصية**
- `/api/health` كان يعرض أسماء الزبائن ومبالغ الطلبات لأي أحد. هسه ما يشتغل إلا بـ `HEALTH_KEY`، وما يعرض أي معلومات شخصية.
- `/api/orders` كان يسمح بقراءة طلبات الناس إذا أحد خمّن أرقامها. هسه كل طلب إله رمز سري ينحفظ بالجهاز اللي سوّاه. واللي مسجّل دخول يشوف طلبات حسابه فقط.
- **تسجيل الدخول صار بجلسة موقّعة.** قبل كان مجرد علامة محفوظة بالجهاز.
- **حذف الحساب يوقف الجلسة فوراً**، ويحرر الإيميل حتى ينعاد التسجيل بيه.
- **الطلبات محمية من التكرار ومن السبام:**
  - الضغط مرتين أو ضعف الشبكة ما يسوي طلبين.
  - في فخ مخفي للروبوتات، وحد لعدد الطلبات من نفس الرقم.
  - مواقع ثانية ما تگدر ترسل طلبات.
- **وصف المنتج من أودو ينظَّف** قبل ما يظهر، فما يمر أي كود.

**الطلبات بأودو**
- **العنوان المكتوب بالطلب ينحفظ كعنوان توصيل مستقل** تحت الزبون. عنوانه القديم ما يتغير، والتوصيل يروح للعنوان الصحيح.
- **رقم الزبون الضيف ما ينربط بحساب شخص ثاني** حتى لو كتب نفس الرقم.
- **تفاصيل الطلب تنكتب كملاحظة داخلية بمحادثة الطلب.** ما تنكتب بحقل «الشروط والأحكام» اللي ينطبع على الفاتورة.
- **الأسعار دائماً من أودو**، مو من الموبايل.
- **رقم الهاتف يُقبل بكل الصيغ**: `07…` و`+964…` والأرقام العربية `٠٧…`، وينحفظ بصيغة وحدة.

**الاستخدام**
- **أجور التوصيل بصفحة الطلب:** الزبون يختار «بغداد» (4,000 د.ع) أو «باقي المحافظات» (5,000 د.ع)، ويشوف المنتجات والتوصيل والكلي قبل ما يأكد. بأودو تنضاف الأجور كسطر مستقل على الطلب، من منتج خدمة اسمه «أجور التوصيل» (الرمز الداخلي `SABA-DELIVERY`). التطبيق يسوّيه تلقائياً أول مرة إذا ما موجود.
- رسالة نجاح الطلب تبيّن رقم الطلب الحقيقي (مثل S00501)، مو الرقم الداخلي.
- قائمة المنتجات بيها «عرض المزيد».
- «رجوع» من المنتج يرجع لنفس القائمة ونفس الفلتر ونفس مكان التمرير.
- طلبات الحساب تبين على كل الأجهزة بعد تسجيل الدخول.
- «اطلبه مرة ثانية» ما يضيف أجور التوصيل للسلة.
- نافذة اللغة صارت فوق الشريط السفلي. قبل كانت تنخفي جوّاه.
- الصور اللي ما تنزل تختفي، بدل علامة الصورة المكسورة.
- صور الأقسام الفرعية كانت مكسورة، هسه تشتغل.

**انحذف**
- شاشة اختيار صيغة المخاطبة (ذكر/أنثى).
- النافذة اللي كانت تفتح موقع أودو داخل التطبيق. كل شي صار داخل التطبيق نفسه.
- رابط «تسجيل الدخول» اللي كان يفتح صفحة دخول أودو. تسجيل الدخول صار بأعلى صفحة الحساب.

## مجرَّب

التطبيق انفحص كامل على متصفح آلي، مربوط بأودو تجريبي يشتغل بنفس طريقة أودو الحقيقي. نجحت 289 فحصة، منها:
- كل رابط داخل التطبيق (167 رابط).
- التابات الست، والبحث بالعربي.
- الماركات العشرين كلها.
- السلة والطلب، وطلباتي، واطلبه مرة ثانية.
- تسجيل حساب ودخول وخروج وحذف الحساب.
- تبديل اللغات الثلاث، والروابط القديمة، وزر الرجوع.
- الحمايات الأمنية.
- ما يطلع شريط تمرير عرضي على الشاشات بعرض 320 و430 و768.

الاتصال بأودو الحقيقي ما ينفحص إلا بعد النشر وإضافة المتغيرات، عن طريق `/api/health`.
