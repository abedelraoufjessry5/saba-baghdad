# صبا بغداد — v2.1

**تصميمك القديم كما هو حرفياً** (ما لمست ولا بكسل منه) + طبقة متجر جديدة فوقه تشتغل على أودو مباشرة.

## شنو تغيّر عن الملفات القديمة

الملفات الأربعة (`index.html`, `categories.html`, `offers.html`, `contact.html`) هيه **نفسها** يلي عندك، الفرق الوحيد سطر واحد مضاف بآخر كل ملف:

```html
<script src="/saba-shop.js" defer></script>
```

كل الوظائف الجديدة بملف `saba-shop.js` لوحده، فأي شي ما عجبك تقدر تشيله بحذف هالسطر ويرجع التطبيق متل ما كان.

## شنو يسوي `saba-shop.js`

- يضيف تابين للشريط السفلي: **سلتي** (مع عدّاد) و**حسابي** — بنفس شكل التابات الموجودة وبنفس دعم اللغات الثلاث.
- أي ضغطة على منتج أو ماركة أو قسم (روابط `saba-baghdad.odoo.com/shop/...`) ما عادت تفتح موقع أودو — تفتح **شاشة داخل التطبيق** تجيب المنتجات من أودو عن طريق `/api`.
- سلة كاملة (إضافة/حذف/كمية) محفوظة بالجهاز، وطلب بالدفع عند التوصيل يسوي `sale.order` **مسودة** بأودو حتى تراجعه قبل ما تأكده.
- حساب: تسجيل/دخول بمستخدم Odoo Portal (مجاني، مو مستخدم داخلي)، مع زر **حذف الحساب** الواضح يلي تطلبه أبل.
- صلّحت تكرار بلوك "شنو تحتاج؟" بصفحة تواصل (كان ينعرض مرتين).

## ⚠️ الخطوة يلي ناقصة عندك حالياً

خطأ "فشل تحميل المنتجات" يلي شفته سببه إنك ما ضفت متغيّرات البيئة بـ Vercel. التطبيق يرد حرفياً:

```
{"error":"Missing Odoo env vars. Set ODOO_URL, ODOO_DB, ODOO_LOGIN, ODOO_API_KEY..."}
```

**الحل:** افتح مشروعك بـ vercel.com → **Settings** → **Environment Variables** → ضيف الأربعة:

| الاسم | القيمة |
|---|---|
| `ODOO_URL` | `https://saba-baghdad.odoo.com` |
| `ODOO_DB` | `saba-baghdad` (إذا ما زبط، شوف الاسم الصحيح بأودو) |
| `ODOO_LOGIN` | `abedelraoufjessry2@gmail.com` |
| `ODOO_API_KEY` | المفتاح حقك (انت تحطه بنفسك — ما أحطه أنا بأي ملف) |

بعد ما تضيفهم لازم **تعيد النشر** (Deployments → آخر واحد → Redeploy) حتى تشتغل.

للتأكد: افتح `https://<مشروعك>.vercel.app/api/products` — لازم ترجع قائمة منتجات، مو رسالة خطأ.

## النشر

```bash
vercel --prod
```
أو ارفع المجلد على GitHub واربطه بـ Vercel.

## مجرَّب

شغّلت التطبيق كامل بمتصفح آلي مع API تجريبي وتأكدت من: ظهور التابين الجداد، فتح قائمة المنتجات من ضغطة على ماركة، الإضافة للسلة وعدّاد التاب، صفحة تفاصيل المنتج، إتمام الطلب، شاشة الحساب، وإن بلوك التواصل المكرر انحذف. الشي الوحيد يلي ما قدرت أختبره هو الاتصال الحقيقي بأودو (شبكة جلستي ممنوعة من الوصول لدومينات برّانية) — هذا يتأكد عندك بعد ما تضيف المتغيّرات.

## باقي

- الصور لسه من سيرفر Mocha — شغّل `node download-assets.mjs` قبل ما تلغي اشتراكه.
- ما بنينا بعد: صفحة "طلباتي" بقسم الحساب، وإشعارات، ونقاط ولاء.

## تعديلات v2.2

1. **لوغوات الماركات** بالرئيسية: صارت شبكة ٤ أعمدة، كل الكروت بنفس الحجم (٤ ريم)، واللوغو كامل يبين بدون قص (`object-fit: contain`) وبدون تمرير أفقي.
2. **زر رجوع** بالشاشات الداخلية: تدخل على منتج من قسم معيّن (مثلاً Cotton Mixtures) وتضغط «رجوع» → ترجع لنفس قائمة القسم بنفس الفلتر، مو للرئيسية. الـ ✕ يسكّر كل شي.
3. **بلوك «شنو تحتاج؟» والفوتر**: انشالوا من صفحتي الأقسام والعروض، وضلوا بس بالرئيسية وبصفحة الحساب.
4. **كل المنتجات متوفرة**: شلت فحص المخزون نهائياً من `/api/products` و`/api/product` (لأن مخزونك مفتوح بأودو) — ما عاد يطلع «غير متوفر» أبداً. وكروت المنتجات صارت كلها بنفس الارتفاع بالضبط (الاسم بثلاث أسطر ثابتة وزر الإضافة مثبّت بالأسفل).
5. **الشريط السفلي** صار: الرئيسية · الأقسام · المنتجات · العروض · سلتي · الحساب — تاب «تواصل» انلغى وصار «الحساب» (نفس الصفحة `contact.html` بكل محتواها) وانضاف فوقها قسم الحساب (دخول/تسجيل/خروج/حذف الحساب).
